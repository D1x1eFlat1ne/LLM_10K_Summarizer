# LLM_10K_Summarizer
This app uses gemini to summarize a 10-k report. 

The app summarizes a 10-K report not only counts the money, but it also gives strategic suggestions on how to improve a company's standing. The AI acts like an Quest-Giver from a video-game which gives it a personality. 

The GUI is loaded with a voice input option where you say the file name, and it will be written in the input.
